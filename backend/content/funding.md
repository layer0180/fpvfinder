# Why there is a donation button

This tool is free, has no accounts, no ads and no paid tier - and it will stay
that way. Every feature is available to everyone.

Running it publicly does cost a little money, though, and donations go towards
exactly that:

- **Hosting** - a small server that keeps the app and its map data cache running
- **Domain** - the yearly registration fee
- **Nothing else** - no salary, no marketing

## Why the cache matters more than the money

The app queries the public [Overpass API](https://overpass-api.de/), which is
donated infrastructure run by volunteers. Every search that hits the cache
instead of Overpass spares that shared resource. Keeping a server with a warm
cache online is therefore as much about being a good citizen of the OpenStreetMap
ecosystem as it is about speed.

## No strings attached

Donations buy no feature, no priority and no support entitlement. If you find
the tool useful and want to chip in, that is genuinely appreciated. If you do
not, please just use it - that is what it is for.
